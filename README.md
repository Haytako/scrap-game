# SCRAP — Постапокалиптическая карточная игра

Карточная игра в стиле Гвинт, вдохновлённая вселенной Fallout. Выжившие сражаются за ресурсы на руинах цивилизации.

## Играть

**[haytako.github.io/scrap-game/](https://haytako.github.io/scrap-game/)**

## Режимы игры

| Режим | Описание |
|-------|----------|
| **Против компьютера** | Сразись с AI противником |
| **Против игрока** | Hot-seat — два игрока на одном устройстве |
| **Онлайн** | Играй с другом на расстоянии через Firebase |

## Как играть

- Каждый игрок начинает с колодой из 35 карт
- В начале партии раздаётся 10 карт
- Ходы чередуются: выложи карту на поле или пасуй
- Три ряда: **Ближний бой**, **Дальний бой**, **Осада**
- Побеждает игрок с большей суммой силы на поле
- **Лучший из 3 раундов** — кто первый выиграет 2 раунда

## Типы карт

### Юниты
Размещаются на один из трёх рядов и добавляют силу к общему счёту.

### Способности
- **Герой** — не подвержен влиянию погоды и способностей
- **Шпион** — размещается на поле противника, вы тянете 2 карты
- **Врач** — воскрешает случайную карту из сброса
- **Мораль** — даёт +1 ко всем юнитам в своём ряду
- **Связка** — одинаковые карты рядом дают +2 каждая

### Погода
- **Ядерная зима** — юниты ближнего боя = 1 сила
- **Рад. туман** — юниты дальнего боя = 1 сила
- **Кислотный дождь** — юниты осады = 1 сила

### Спецкарты
- **Рассвет** — очищает всю погоду
- **Огненный шторм** — уничтожает самую сильную карту на поле

## Онлайн-мультиплеер

Для игры онлайн требуется настройка Firebase Realtime Database:

1. Создайте проект на [console.firebase.google.com](https://console.firebase.google.com)
2. Включите **Realtime Database** в тестовом режиме
3. Добавьте Web-приложение и скопируйте конфиг
4. Вставьте конфиг в `FB_CONFIG` в файле `index.html`

Подробная инструкция по настройке Firebase доступна в комментариях внутри `index.html`.

## Технологии

- Чистый HTML + CSS + JavaScript (без фреймворков)
- Firebase Realtime Database для онлайн-мультиплеера
- SVG векторная графика для иконок карт
- CSS CRT-эффекты (scanlines, vignette, flicker)
- Адаптивный дизайн (мобильные устройства + десктоп)
